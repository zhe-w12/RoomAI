# RoomAI

RoomAI 是一个面向小团队的立项讨论聊天室。伙伴通过邀请链接或 6 位邀请码进入房间，围绕一个主题实时讨论；RoomAI 可以生成讨论开场、准备问题，并在成员召唤时梳理讨论内容。

项目按 [DESIGN.md](./DESIGN.md) 推进。技术栈为 FastAPI + WebSocket、LangGraph + SQLite checkpoint、React + Vite + TypeScript + Tailwind；界面优先适配手机，采用白底灰阶与细线布局。部署不在当前阶段范围内。

## 本地运行

### 1. 配置模型

复制 `.env.example` 为项目根目录下的 `.env`，填入兼容 OpenAI Chat Completions 接口的密钥。默认配置使用 `https://aiping.cn/api/v1` 和 `GLM-5.3-Flash`。需要联网评估时，还要设置 Tavily 的 `TAVILY_API_KEY`；评估维度可通过 `EVALUATION_DIMENSIONS` JSON 数组调整，LangGraph checkpoint 路径可通过 `LANGGRAPH_CHECKPOINT_PATH` 调整。`.env` 只保存在本地，不要提交到 Git。

### 2. 启动后端

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

后端 API 文档地址：<http://localhost:8000/docs>。

### 3. 启动前端

另开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

打开 <http://localhost:5173> 创建房间。创建者可复制邀请链接分享给伙伴；加入者也可在首页输入邀请码。

## 已实现

- 创建房间、生成 6 位邀请码、通过邀请码或链接加入；昵称在房间内唯一。
- 创建房间时可选择自由讨论、技术选型、产品立项或活动策划模板，也可设置可选房间密码；加入链接和邀请码均会校验已设置的密码。
- SQLite 持久化消息和访客；WebSocket 广播消息、在线成员、输入状态和阶段变化，断线后指数退避重连最多 5 次，并按最后消息 ID 补齐漏掉的消息。
- `@RoomAI` 对话与红队回复通过 WebSocket 流式显示；LangGraph Supervisor 按房间路由普通对话、联网评估、滚动总结分析和投票提案，使用 `session_id` 作为 `thread_id`，checkpoint 保留最近四轮 Agent 上下文。
- 输入草稿按房间和成员保存在浏览器 `localStorage`，刷新后恢复，发送后清除。
- 房主可在设置里永久删除房间，级联清除讨论数据并删除房间上传的图片和资料文件。
- 图片附件（JPG / PNG / WebP / GIF，单张不超过 5MB）、引用回复、两分钟内撤回。
- `@` 成员提醒、未读提醒跳转、房主切换发散 / 收敛阶段。
- `/总结`、`/评估`、`/投票`、`/画图`、`/挑战`、`/用户视角`、`/待办`、`/结束`、`/帮助` 和 `@RoomAI` 对话入口；用户视角输出会明确标注为模拟反馈。
- 发散阶段可通过输入区匿名提交想法；同伴只看到“匿名成员”，匿名内容不绑定访客身份、不生成 @提醒或 typing 广播，随后由 RoomAI 汇总并评估。
- 建房时生成开场消息与准备问题；模型调用失败或未配置密钥时使用本地开场文案。
- 房间在 1 分钟内无人发言且累计至少 3 条新消息时，自动生成版本化总结、提取待办并评估新想法；每累计 20 条消息也会触发兜底分析。阈值可通过 `.env` 配置。
- 总结版本、想法、六维评分、待办和模型 Token 用量保存在 SQLite；总结、想法池与讨论维度会在侧栏更新。
- 成员可以对想法投支持或反对并随时改票；房主可把想法标记为讨论中、待定、已采纳或已否决，状态变化会保存在回放历史中。重复想法合并时记录可识别的补充者，排序综合六维均分和支持 / 反对数。
- 最近讨论中的图片会随多模态请求发送；每轮分析会保存图片的一句客观摘要，供较早图片的后续讨论检索；聊天、总结和评估请求都记录 Token 用量。费用单价可在 `.env` 配置。
- 房主可在房间设置中切换模型；`AVAILABLE_MODELS` 配置允许选择的兼容模型。
- 房间关键词搜索支持检索消息、想法、总结、纪要和图片说明；结果包含想法评分与匹配摘要，并可跳回讨论消息或打开纪要。
- 滚动总结可查看最近 20 个版本；讨论回放按时间展示发言、总结、想法、评估、投票和决策，并可跳回原消息。
- `/投票` 或 `@RoomAI 发起投票` 会按现有讨论生成投票卡；成员可改票，票数实时同步，房主可提前结束，5 分钟后自动结束并归档结果。
- 收敛阶段输入 `/对比` 可并排查看候选方案的配置维度评分、已记录优势与代价、评估依据及成员支持情况；滚动总结会提示需要团队拍板的关键决策。
- 输入 `/联网评估 候选方向` 可使用 Tavily 搜索外部证据，再由 RoomAI 区分来源事实、讨论结论和待验证假设，并附可追溯链接；需要在服务器 `.env` 配置 `TAVILY_API_KEY`，不会在每轮自动总结时产生检索费用。
- 房间可添加最多 20 份 PDF、DOCX、PPTX、TXT 或 Markdown 资料（单份不超过 10MB）；内容保存在服务器私有目录并切分、向量化，RoomAI 回答时按相关度检索片段并标注文件来源。扫描版 PDF 暂不支持 OCR。
- 输入区提供中文语音转写，识别结果会回填为可编辑草稿，确认后再发送；语音识别由浏览器提供，部分浏览器可能会联网处理音频，且不同浏览器的支持情况不同。
- 讨论回放按时间展示发言、总结、想法、评估、投票、决策和待办；总结历史可查阅最近 20 个版本。
- 分歧分析会在没有未结束投票时自动生成投票卡；抽取出的待办会作为交互卡片附在对应 AI 消息下，成员可直接勾选完成或打开编辑负责人、状态和截止日期，修改实时同步。
- 房主结束讨论前可检查用户、技术、时间、成本和风险维度；确认后生成可阅读的立项纪要、正式立项书草稿和复盘，支持 Markdown、Word 和浏览器打印导出 PDF。
- 收敛阶段可自动发起最多三次红队审查；房主可在设置中关闭，也可用 `/挑战` 手动调用。阶段提示、讨论引导及基于想法提出者的智能 @ 建议随消息呈现。
- AI 生成的 Mermaid 方案图在消息和纪要中渲染，支持放大和导出 SVG；评估维度可按项目配置。
- 立项纪要附带项目时间线草案；只有能在讨论或明确待办中找到原文依据的里程碑与时间才会写入。
- 滚动分析会给出群体讨论氛围观察（活跃、平稳、偏冷或存在分歧）及 RoomAI 下一轮的节奏调整建议；仅依据可观察的群体互动，不判断个人情绪。
- 房间连续 30 天无活动后自动删除，满 27 天时在房间中提醒一次；发言、加入或更新讨论内容会重置清理计时。天数和检查间隔可通过 `.env` 配置。
